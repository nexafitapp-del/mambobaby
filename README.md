# Meu novo app
Aplicação React 19 com TypeScript 5, Vite 7 e Tailwind CSS 4.
Use Node.js 22.12 ou superior.
Instale as dependências com `npm ci`.
Inicie o desenvolvimento com `npm run dev`.
Valide os tipos com `npm run typecheck`.
Gere a versão de produção com `npm run build`.
Confira a produção localmente com `npm run preview`.
Edite a página inicial em `src/App.tsx`; os componentes ficam em `src/components/ui`.
O tema Branco · Cobalto fica em `src/index.css`; publique a pasta `dist`.
